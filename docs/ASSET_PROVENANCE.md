## What has deliberately _not_ been done

No stock photography, AI-generated imagery, or placeholder product shots have
been introduced anywhere. Surfaces that would show brand imagery render their
empty state instead. The brief is explicit that a missing asset should be
recorded rather than filled with generic material, and that is what has happened.

The wordmark in the header and footer is set in type
(`src/components/ui/Wordmark.tsx`) rather than being an invented logo. Replacing
it with the official artwork is a change to that one component.

## How assets will be handled once available

The importer, when it can run:

1. reads the public catalog once — never at request time;
2. downloads each image and writes it to `public/assets/products/` with a
   readable filename (`<slug>-<position>-<hash>.<ext>`);
3. records alt text, using the source's own alt where present and a factual
   description otherwise;
4. regenerates this file with a row per asset: local path, original URL,
   product, and alt text;
5. lists any asset that failed to download in a separate table, so a gap is
   visible rather than silently absent.

Images are stored in the repository rather than hotlinked, so the storefront has
no runtime dependency on the legacy site. Crops and resizes for layout are
applied at render time via `next/image`; no edit alters how a garment or a
person actually appears.
