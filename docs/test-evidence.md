## How to reproduce

```bash
npm ci
npm run typecheck && npm run lint && npm test
CHECKOUT_MODE=permalink npm run build
npx playwright test
```

Notes: Playwright starts `next start` with a throwaway PGlite database (`.data/e2e-pglite`, wiped per run), a test owner and `CHECKOUT_MODE=permalink`. Build with the same `CHECKOUT_MODE`, because statically rendered pages capture it at build time. `next start` keeps revalidated ISR pages in `.next`, so rebuild before demoing after a test run.
